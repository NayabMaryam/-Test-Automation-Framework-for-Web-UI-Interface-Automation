# UI Test Automation Framework

## Project Overview

This project aims to develop a modular, scalable, and reusable Web UI Test Automation Framework using Python and Playwright.

The framework will support:

- Web UI automation
- Behavior-Driven Development (BDD)
- Gherkin-based test scenarios
- Page Object Model (POM)
- Data-driven testing
- Excel, Database, and Redis integration
- Allure reporting
- GitHub Actions for Continuous Integration

## Project Structure

The project is organized into separate modules for browser management, page objects, test scenarios, test data, reporting, and documentation.

## Technologies

- BDD Framework (To be finalized)
- Allure Report
